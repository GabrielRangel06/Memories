# Fati — a thread becomes a time capsule

## Director’s treatment

- **Promise:** 61 ordinary screenshots can make one friendship feel like a place you can return to.
- **Identity:** After-hours archive editorial crossed with a precision motion-graphics UI: ink-plum, warm archive paper, a persimmon signal red, Instrument Serif display against DM Sans and Space Mono labels.
- **Hero:** The original Discord conversation screenshots, treated as real artifacts rather than recreated UI.
- **Motion:** Each onset-cut screenshot gets its own masked plate reveal, restrained virtual-camera push/pull, and small perspective drift. A persistent vermilion archive rail, corner registration marks, and parallax grid carry continuity without repainting the source material.
- **Arc:** Start in the football banter at full speed, move through a broader run of shared jokes, then let the last intimate fragments breathe.
- **Payoff:** Screenshot 60 contracts into a memory field; screenshot 61 resolves full-frame as the final artifact. The top archive rule and restrained camera position match the opening for a clean loop.
- **Format:** 16:9 landscape.

Chapter title enters at 00.18s; it tucks away before the chapter handoff.
2. **02 / 08.70–19.25 — “El hilo no termina”**. The incoming screenshot lands with the same frame position as the preceding image while a persimmon panel crosses the upper edge. Screenshots 21–41 cut faster through the central run; periodic wider holds allow dense messages to read. The end settles into one slow push rather than a wipe.
3. **03 / 19.25–29.85 — “Y de pronto, una foto”**. The plate opens left-to-right, then shifts to a center-weighted composition. Screenshots 42–50 are allowed longer holds as the material changes from chat-heavy panels to photos and voice notes. A very thin split line and paper-colored frame replace the earlier panel accents.
4. **04 / 29.85–41.05 — “Lo que queda entre líneas”**. The last 11 screenshots breathe: small beats still occur at every cut, with continuous slow camera travel during long intervals. Screenshot 60 contracts into the memory field; screenshot 61 arrives full-size on the final accent. The red rail holds its top-edge position so the loop restarts as a graphic match.

### Transition contract

Every screenshot transition combines image scale/position choreography with a split-panel or rail movement; a shared persimmon archive rule is the carrier. Each chapter boundary also combines an incoming matched image settle with a two-part color reveal. The last-to-first handoff matches the rail's position and direction. No scene waits for an exit before its successor is mounted.
